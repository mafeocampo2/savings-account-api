💰 Sistema de Ahorros

Aplicación Bancaria Web - Frontend + API REST

Desarrollado con HTML, CSS, JavaScript y Node.js

¿Qué es?

Sistema de Ahorros es una aplicación web bancaria que permite a los usuarios:

  • ✓ Crear cuentas de ahorro
  • ✓ Realizar depósitos
  • ✓ Hacer retiros
  • ✓ Ver el historial de transacciones
  • ✓ Eliminar cuentas

Diseño profesional con modo oscuro incluido

Arquitectura: 7 Páginas HTML

  • index.html - Selección y listado de cuentas
  • crear.html - Formulario para abrir nueva cuenta
  • gestion.html - Vista principal de gestión (?cuenta=id)
  • accion.html - Paso 1: Ingreso de monto (?cuenta=id&tipo=)
  • confirmar.html - Paso 2: Confirmación de operación
  • comprobante.html - Resultado con comprobante

Flujo de Usuario

index.html → crear.html → gestion.html ↓ accion.html (monto) ↓ confirmar.html (check) ↓ comprobante.html (recibo) ↓ gestion.html (regresa)

Regla clave: El ID de cuenta vive en la URL (?cuenta=X), nunca en localStorage.

Stack Tecnológico

  • Frontend: HTML5, CSS3, JavaScript Vanilla
  • Tipografía: Archivo (interfaz), IBM Plex Mono (números)
  • Backend: Node.js + Express
  • API: REST endpoints (GET, POST, DELETE)
  • Datos: En memoria (array de cuentas)
  • Almacenamiento: sessionStorage (flujo multi-paso)

Endpoints REST

GET /api/accounts → Listar todas las cuentas
POST /api/accounts → Crear nueva cuenta
GET /api/accounts/:id → Obtener detalles de 1 cuenta
POST /api/accounts/:id/deposit → Depositar dinero
POST /api/accounts/:id/withdraw → Retirar dinero
DELETE /api/accounts/:id → Eliminar cuenta

Sistema de Diseño

  • Colores: Navy (#332F4A), Verde (#146D34), Rojo (#9A322A)
  • Botones: Outline style (borde sin relleno)
  • Espaciado: Grid system 32px, cards con 30px padding
  • Dark mode: CSS variables con data-theme attribute
  • Responsive: Mobile-first, breakpoint en 768px
  • Transiciones: 0.2s ease en todos los cambios

Características de Seguridad

  • ✓ Botón "Confirmar" se deshabilita al hacer clic (evita doble-envío)
  • ✓ Validación de montos en cliente y servidor
  • ✓ Estado vacío cuando no hay cuentas
  • ✓ Manejo de errores de API con mensajes claros
  • ✓ Búsqueda de cuentas en cliente (sin servidor)
  • ✓ Preview en vivo de saldos finales

Funciones Principales

api.js:
• formatCOP(n) - Formatea números como pesos
• parseAmount(str) - Parse montos con separadores
• getAccounts() - Fetch lista de cuentas
• deposit/withdraw/deleteAccount() - Operaciones
En cada página:
• init() - Carga inicial y health check
• toggleTheme() - Cambio de modo oscuro
• updatePreview() - Preview en vivo de operaciones

Flujo Detallado: Depositar $150.000

1. gestion.html: Usuario hace clic en "Depositar"

2. accion.html: Ingresa monto (150000), ve preview en vivo

3. sessionStorage: Guarda { accountId, tipo, amount }

4. confirmar.html: Muestra resumen antes/después

5. API POST: /api/accounts/1/deposit { amount: 150000 }

6. comprobante.html: Recibo con número y timestamp

7. Regresa: gestion.html con saldo actualizado

Parsing de Montos Inteligente

function parseAmount(str) {
  // Remueve separadores de miles
  const cleaned = str.replace(/\./g, '')
                    .replace(/,/g, '.');
  return parseFloat(cleaned) || 0;
}

Permite: 100.000, 100,000, 100000
