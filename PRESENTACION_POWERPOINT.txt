DIAPOSITIVA 2: ¿QUÉ ES?
================================================================================
TÍTULO:
¿Qué es Libreta de Ahorros?

CONTENIDO:
Libreta de Ahorros es una aplicación web bancaria que permite a los usuarios:

✓ Crear cuentas de ahorro
✓ Realizar depósitos
✓ Hacer retiros
✓ Ver el historial de transacciones
✓ Eliminar cuentas

NOTA:
Diseño profesional con modo oscuro incluido


DIAPOSITIVA 3: ARQUITECTURA DE PÁGINAS
================================================================================
TÍTULO:
Arquitectura: 7 Páginas HTML

CONTENIDO:
• index.html
  Selección y listado de cuentas

• crear.html
  Formulario para abrir nueva cuenta

• gestion.html (con ?cuenta=id)
  Vista principal de gestión

• accion.html (con ?cuenta=id&tipo=)
  Paso 1: Ingreso de monto

• confirmar.html
  Paso 2: Confirmación de operación

• comprobante.html
  Resultado con comprobante

• (7 páginas total para flujos limpios)


DIAPOSITIVA 4: FLUJO DE USUARIO
================================================================================
TÍTULO:
Flujo de Usuario - Paso a Paso

CONTENIDO:
index.html
    ↓
    ├→ crear.html (nueva cuenta)
    │
    └→ gestion.html?cuenta=X
        ├→ accion.html (monto)
        │  └→ confirmar.html (check)
        │     └→ comprobante.html (recibo)
        │        └→ gestion.html (regresa)

REGLA CLAVE:
El ID de cuenta vive en la URL (?cuenta=X), nunca en localStorage.
Esto permite que el botón "atrás" funcione naturalmente.

DIAPOSITIVA 6: ENDPOINTS DE API
================================================================================
TÍTULO:
REST API - Endpoints

CONTENIDO:
GET  /api/accounts
  → Listar todas las cuentas

POST /api/accounts
  → Crear nueva cuenta

GET  /api/accounts/:id
  → Obtener detalles de 1 cuenta

POST /api/accounts/:id/deposit
  → Depositar dinero

POST /api/accounts/:id/withdraw
  → Retirar dinero

DELETE /api/accounts/:id
  → Eliminar cuenta

DIAPOSITIVA 10: FLUJO DETALLADO - DEPOSITAR
================================================================================
TÍTULO:
Flujo Completo: Depositar $150.000

PASO A PASO:
1. Usuario en gestion.html hace clic en "Depositar"
   ↓
2. Navega a accion.html?cuenta=1&tipo=deposito
   ↓
3. Ingresa "150000" en input
   ↓
4. Preview en vivo: saldo final = 1.150.000
   ↓
5. Hace clic en "Siguiente"
   ↓
6. Guarda en sessionStorage: {accountId, tipo, amount}
   ↓
7. Navega a confirmar.html
   ↓
8. Muestra resumen antes/después
   ↓
9. Hace clic en "Confirmar"
   ↓
10. Botón se deshabilita (evita doble-envío)
    ↓
11. POST /api/accounts/1/deposit { amount: 150000 }
    ↓
12. Servidor valida y responde con nuevo saldo
    ↓
13. Navega a comprobante.html
    ↓
14. Muestra: ✓ Depósito completado, $ 150.000, comprobante
    ↓
15. Usuario hace clic "Volver"
    ↓
16. Regresa a gestion.html?cuenta=1 con saldo actualizado


DIAPOSITIVA 11: VALIDACIÓN DE MONTOS
================================================================================
TÍTULO:
Parsing Inteligente de Montos

FUNCIÓN:
function parseAmount(str) {
  // Remueve separadores de miles
  const cleaned = str.replace(/\./g, '')
                      .replace(/,/g, '.');
  return parseFloat(cleaned) || 0;
}

PERMITE:
✓ 100.000 (separador punto español)
✓ 100,000 (separador coma)
✓ 100000 (sin separadores)

TODOS DEVUELVEN: 100000
